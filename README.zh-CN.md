# Poster Genome · 海报基因 🧬

> **看懂好设计，学会它的设计逻辑，再创造属于自己的海报。**

Poster Genome 是开放源码的 **Agent Skill（智能体技能）**，而不是独立运营的在线生图网站。它把「海报学习 → 设计基因提取 → 素材适配 → 智能创作 → 质量评审」串成一个能不断积累知识的流程。

[English](README.md) · [SKILL.md](SKILL.md)

## 这和普通海报提示词有什么不同？

普通提示词描述一张图应该长什么样。Poster Genome 试图解释：**为什么这种构图能让人看下去、这类配色在什么场合有效、主体和文字为什么要这么安排，以及换一张照片后哪些规则仍然成立。**

### 1. 学习模式 Learn

输入：你喜欢的一张参考海报。输出：

- **素材清单**：人物/物品/环境/插画/装饰/文字等，数量、占比、位置及作用；
- **视觉骨架**：画布比例、网格、主体重心、视觉动线、留白、层级和阅读顺序；
- **视觉语言**：风格、色系、对比、光影、肌理、画质、景深和色彩关系；
- **文案/字体**：主副标题、字号相对关系、字重、字距、行距、对齐方式、情绪（未知的具体字体不能乱猜）；
- **原因与边界**：哪些设计决定让作品有效；什么素材、场景或文案长度不适合；
- **可迁移设计基因**：结构化 JSON，独立命名、版本化、可校验、可组合。

分析要严格区分：画面可直接观察的事实、基于经验的推断、无法确认的细节。保存新基因前必须经过用户确认，默认不把参考图纳入公开仓库。

### 2. 创作模式 Create

输入：你的照片/图片（以及可选文案或要求）。

工作流：先检查画面 → 只问必要信息 → 构建创作 brief → 检索匹配基因 → 规划构图与文字 → 用实际可用的生图/修图工具创作 → 质量审核 → 交付。

可能询问的关键信息：**做给谁/用在哪里？海报必须写什么？尺寸或比例是什么？** 已知的不要重复问；不重要的先采用合理默认值。模型选择海报基因时，要说明适配理由，不能盲目按喜欢程度排行。

### 3. 审美评审 Refine

根据主体识别、信息层次、构图、颜色、文本准确性、排版、视觉杂讯和成品技术质量进行评审。优先修复阻碍理解或影响发布的缺陷；区分硬错误和个人风格偏好。

## 快速安装

需要支持 [Agent Skills](https://agentskills.io/specification) 的 AI 客户端。将整个仓库放到客户端可识别的 `poster-genome` 技能目录（例如支持 `~/.agents/skills` 的客户端）：

```bash
git clone https://github.com/gmchocolate/poster-genome.git
mkdir -p ~/.agents/skills
ln -s "$(pwd)/poster-genome" ~/.agents/skills/poster-genome
```

其他客户端的项目级/用户级安装路径可能不同，以客户端文档为准。安装后可直接对视觉模型说：

> 用 poster-genome 学习这张海报，先深度分析，给我候选设计基因，不要未经允许写入项目。

> 用 poster-genome 给这张照片制作一张高级、有电影质感的 4:5 竖版海报。标题是「秋日物语」，其余你来判断，只问必要问题。

> 用 poster-genome 对这张成品做审美审核，文案一个字都不要改。

**本地设计基因检索（只用 Python 标准库）**：

```bash
python scripts/match_genomes.py --subject person --intent editorial --mood cinematic --ratio 4:5
python scripts/match_genomes.py --input examples/brief-example.json --top 2
```

**校验（Python 3.10+）**：

```bash
python -m pip install -r requirements-dev.txt
python scripts/validate_library.py
python -m unittest discover -s tests -v
```

## 当前版本边界

- ✅ 标准 Skill 入口、视觉分析和创作方法、增量基因库、自动规则匹配、JSON Schema、校验与测试
- ✅ 两个**原创演示基因**，用于展示如何描述风格；不是从特定设计师海报复制出来的
- ⚠️ 视觉识别、实际生图与修图，需要宿主 AI 真正具备相关工具。本仓库不提供视觉模型/API 密钥，也不宣称能在命令行直接生成全部复杂海报
- ⚠️ 真实汉字、价格、品牌 LOGO 等精确信息应优先由确定性文字/图形工具排版并复核
- ⚠️ 不自动发布参考作品，不默认重建原作者的可识别完整排版

## 后续值得扩展的方向

基因去重与融合、基于多参考图的共性抽取、真实成品的 A/B 评测、可视化选型面板、确定性文字排版器、印刷 PDF/出血/CMYK 校验，以及在拥有工具时的生图和修图适配器。
